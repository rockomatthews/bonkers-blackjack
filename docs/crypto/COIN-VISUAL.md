# Bonkers 3D coin

`src/Coin3D.tsx` loads a browser-only Three.js scene from `src/coin-scene.ts`. The cylinder and two raised rims are white. Separate circular meshes use the supplied red heads and blue tails PNGs. The original files are copied unchanged into `public/coins`; texture UVs exclude their square outer margins. No artwork or outcome is generated by the animation.

The pending wager flips the mesh, then the verified receipt determines its final side (the majority for 11/21-toss batches). Selecting a side previews that face before a result exists. Reduced-motion preferences suppress the flip. Rendering pauses offscreen or while the document is hidden; idle coins render on demand, pixel ratio is capped at two, and GPU resources are disposed on unmount. A WebGL failure displays the corresponding supplied image with a white border.

The homepage preview and game choice buttons use the same artwork. The financial contracts, payout rules, deposit gates and shared reserve accounting are unchanged by this visual update.

Verification: production build and TypeScript pass. Five local browser tests cover both actual WebGL-rendered faces, visible white pixels, mobile overflow, reduced motion, no-WebGL fallback, pending flips and receipt-selected landing sides for 1/11/21 tosses, plus the existing wallet regressions. All financial test transactions use disposable Anvil/mock USDC. Screenshots: `coin-3d-heads.png`, `coin-3d-tails.png` and `coin-3d-mobile.png` in `docs/screenshots`.
